# BOOMiiS Restaurant

Mobile-first brand site for BOOMiiS Restaurant, 47 Adjiringano Road, East Legon, Accra.

Static site (no build step): `index.html`, `styles.css`, `main.js`, `assets/`.
Highlights: scroll-directed WebGL hero, WhatsApp reservation form, sticky mobile action dock.

Run locally: `python3 -m http.server`
